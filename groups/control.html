EMBEDDED CONTROL

电气控制组

让机械结构真正动起来，让硬件板卡发挥作用，让视觉结果进入机器人动作：电控组负责从底盘、云台、发射机构和机械臂控制，到裁判系统通信、测试装置支持、整车状态与赛场联调的完整控制闭环。

查看组别成员

CONTROL LOOP

从传感输入到可验证动作

电控交付的不是孤立代码，而是一条能够实时运行、与整车接口匹配，并在赛场压力下保持稳定的控制链路；日常研发与调试通常以兵种为基本责任单元。

01感知与输入

接入编码器、IMU、裁判系统与视觉目标数据，建立可信的机器人状态输入。

02估计与解算

完成运动学解算、姿态估计、滤波与坐标转换，把原始数据变成控制量。

03闭环控制

使用 PID、LQR 等方法调节底盘、云台、发射与机械臂执行机构。

04通信与状态

通过 CAN、串口及模块接口组织整车通信、状态机与异常处理。

05联调与验证

用实时监视、示波器、日志和赛场测试定位问题，完成回归与交付。

PROJECT CASES

四条核心控制项目线

选择项目查看控制系统如何进入不同机器人。案例保留仿真、整车和现场画面，用闭环结果说明每项工作解决什么问题。

CHASSIS CONTROL

让不同构型的底盘稳定、敏捷地运动

覆盖麦克纳姆轮、全向轮、舵轮与串联轮腿等构型。项目需要完成运动学解算，结合 PID、LQR 或强化学习等控制方法，并在真实负载和碰撞扰动下兼顾机动性与鲁棒性。

  • 运动学模型
  • PID / LQR / RL
  • 轮腿与多构型
  • 实时调参

GIMBAL CONTROL

把姿态反馈、自瞄结果与发射时序连成闭环

以 IMU 姿态反馈完成 Pitch 与 Yaw 两轴闭环，使云台快速响应并稳定跟随，为自瞄锁定、弹道解算和发射时序提供可执行基础。

  • 姿态反馈
  • 两轴闭环
  • 自瞄接口
  • 发射时序

ARM & CONTROLLER

让多关节机械臂可解算、可规划、可操控

围绕能量核心抓取与装配任务，以多关节运动学、轨迹规划和力矩闭环实现末端精准定位，并适应碰撞与负载变化；自定义控制器同步位姿，以同构操作和重力补偿改善操控体验。

  • 多关节解算
  • 轨迹规划
  • 力矩闭环
  • 远程同步

DART SYSTEM

让镖架发射与镖体制导共同完成命中

镖架侧统一调度舵机与电机，组织装配、自瞄和发射时序；镖体侧结合目标引导信息实时解算并修正弹道，让两套控制系统协同交付。

  • 时序控制
  • 传感反馈
  • 目标引导
  • 弹道修正

SYSTEM INTEGRATION

电控是整车系统的中枢神经

只有结构、板卡、算法和控制接口一起工作，机器人才能从“各模块可用”走向“整车可靠运行”。

MECHANICAL

与机械组匹配执行器与结构

共同处理电机选型、减速比、负载、安装空间和线缆走线，让控制指令能够准确转化为机械动作。

VISION

与视觉组打通实时数据链路

通过 USB 对接目标坐标、识别和预测结果，处理坐标转换、时间戳同步、传输延迟与控制补偿。

HARDWARE

与硬件组保证供电和信号可靠

围绕电源分配、PCB 接口、信号完整性与 EMC 抗干扰排查问题，使主控和传感器在复杂电磁环境下稳定工作。

WHAT YOU BUILD

在电控组形成怎样的工程能力

学习对象不只是一组算法或外设，而是从底层驱动到整车协作、从实现功能到证明可靠的完整嵌入式工程过程。

嵌入式技术栈

STM32 外设、DMA、FreeRTOS、CAN 与串口通信，以及面向实时系统的代码组织。

控制理论落地

把 PID、LQR、运动学与卡尔曼滤波放入真实机器人，用动态响应而不是公式截图验证效果。

系统调试与排障

结合断点、实时监视、万用表、示波器和日志定位软硬件边界上的问题。

项目交付与版本意识

经历方案、实现、联合调试、赛场维护和复盘，保留代码版本、接口与测试记录。

跨专业系统视野

学会把机械约束、视觉输出、硬件能力和战术需求放进同一套整车判断中。
