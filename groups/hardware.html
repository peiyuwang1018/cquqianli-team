HARDWARE DEVELOPMENT

硬件开发组

把赛场规则和机器人需求变成真正可用的电路：硬件组负责能源系统、自研板卡、接口与传感器、测试装置，以及整车供电、通信和电气可靠性支持。

查看组别成员

HARDWARE WORKFLOW

从规则需求到可靠上车

硬件工作不止是画板和焊接。真正的交付要经历功率、接口和环境约束分析，并通过台架测试和整车联调证明板卡可靠。

01规则与需求

从比赛规则、整车任务和上下游接口中拆出电气指标、边界与风险。

02电路与器件

完成电源、信号、保护与传感链路设计，选择满足工况的器件和方案。

03PCB 与样机

进行原理图、布局布线、焊接和样机制作，把方案变成可接入的实体板卡。

04台架与验证

使用电源、负载和示波器检查效率、波形、温升、保护与异常边界。

05整车与维护

完成供电、通信和机械接口接入，并在联调与赛场维护中闭环故障。

PROJECT CASES

七类赛场硬件项目

选择项目查看板卡、台架与接口如何进入机器人。长期核心项目与现场支持任务都按同一条工程链路接受验证。

SUPERCAPACITOR

在功率限制与瞬态机动之间管理能量

系统在功率富余时储能，在机器人加速等瞬态工况下释放能量，以“削峰填谷”支持底盘机动。项目同时涉及功率变换、能量管理、保护和整车通信。

  • 功率变换
  • 能量管理
  • 大电流保护
  • 多版本迭代

WIRELESS CHARGING

用效率、容差与战术时间共同判断方案价值

围绕赛场补充缓冲能量的需求，完成发射与接收侧功率电路、线圈接口、控制和验证，并权衡充电效率、对位容差、驻留时间和整车战术。

  • 磁耦合
  • 功率电路
  • 效率与波形
  • 战术权衡

DART HARDWARE

在有限体积与重量中完成供电和控制接口

镖体板卡接入供电、裁判系统与控制链路，并为姿态感知与制导功能预留硬件基础。

  • 小型化
  • 供电接口
  • 姿态传感

RUNE TEST DEVICE

为视觉与电控提供可重复的目标环境

自制能量机关复现目标与灯效，为视觉识别、自瞄和快速击打训练提供稳定测试条件。

  • 灯效控制
  • 测试复现
  • 跨组支持

AERIAL SYSTEM

围绕新赛季约束重新平衡动力、重量与安全

硬件成员参与电机、电调、飞控和近场感知相关选型与调试。面对小型化、桨保护和集群飞行等约束，项目需要同时考虑续航、安全与感知能力。

  • 动力选型
  • 飞控调试
  • 轻量化约束
  • 近场感知

该方向仍在随赛季规则与整机方案持续定义，页面仅呈现当前硬件任务边界。

RADAR DEMODULATION

把无线电信号解析成可供战术系统使用的数据

通过雷达搭载的硬件模块处理并解析官方设备输出的无线电信号，将对手机器人信息接入战术决策。该方向自 2026 赛季开始建设，仍处于技术积累期。

  • 射频信号
  • 滤波解析
  • 数据接口

HARDWARE SUPPORT

用小型板卡和接口件保障整车开发继续推进

磁编码器、手持装甲板、分电板、线材与测试转接板不一定属于某一辆机器人，却直接决定开发和联调能否继续推进。

  • 编码与传感
  • 分电与线束
  • 测试转接
  • 现场维护

WHAT YOU BUILD

从板卡设计到硬件可靠性

硬件项目的价值不只在于板卡点亮，而在于能够理解能量和信号如何流动、证明设计边界，并让它在整车环境中长期工作。

电源与功率电子

理解供电、功率变换、储能、保护和高电流路径，处理效率与温升问题。

原理图与 PCB

从器件选型和原理图进入布局布线、封装、制板、焊接与版本迭代。

测试与故障定位

通过电源、电子负载、示波器和分段验证判断波形、噪声与异常根因。

接口与系统集成

处理供电、通信、传感器、机械安装与电控接口，让板卡真正进入机器人。

可靠性与维护

关注保护、抗干扰、连接可靠、可测试和可维修，并在联调中闭环问题。

BENCH BASICS

先看懂、焊好、测准

从电路基础、常用器件、焊接和仪器使用开始，建立安全与规范意识。

02
BOARD PROJECT

完成一块可验证板卡

在指导下经历需求、原理图、PCB、样机与测试，理解每次修改的证据。

03
SYSTEM DELIVERY

进入整车与赛场闭环

承担接口、联调和维护责任，把单板性能放进真实负载和系统环境验证。
