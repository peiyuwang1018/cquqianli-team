MECHANICAL STRUCTURE

机械结构组

从任务定义到赛场维护，把结构设计、分析验证、加工装配与测试迭代连成一条完整工程链路。机械组不只负责“画图”，更要让机器人被制造出来、可靠运行并持续迭代。

WHAT WE BUILD

我们负责什么

机械结构组承担竞技机器人本体从方案到实物的主要工程工作，并与电控、视觉、硬件和兵种负责人共同完成整机交付。

  1. 01

    需求与整机方案

    把规则、战术任务、重量与空间约束转化为结构指标，完成布局、模块边界和跨组接口定义。

  2. 02

    机构与结构设计

    负责底盘、云台、发射、取放、传动与执行机构的建模、选型、校核和方案评审。

  3. 03

    制造、装配与集成

    输出工程图与加工信息，参与材料和工艺选择，把零件组装为能够进入整车联调的真实系统。

  4. 04

    测试、维护与迭代

    通过测试记录、故障定位、版本管理和赛场维护，持续提升性能、可靠性与可维护性。

HOW WE WORK

组内习惯与要求

这里先呈现机械组希望长期坚持的工作方式；后续可以继续补充真实 SOP、评审模板和赛季传统。

01

先说清需求与接口

开始建模前明确任务、边界、输入输出和验收条件，避免把跨组问题留到整车联调阶段。

02

让方案经得起评审

重要结构需要说明依据、风险和备选方案；设计决策应能够被复核，而不是只依赖个人经验。

03

对制造与维护负责

设计时同步考虑加工、装配、走线、拆装和赛场抢修，模型完成不等于工程交付完成。

04

用记录完成传承

保留版本、测试结果、故障原因和改进结论，让下一位负责人能从已有成果继续向前。

一套机械系统的完成，不以模型画完为终点，而以它能够制造、装配、联调、维护并可靠上场为标准。

FIRST-YEAR POSITIONING

先适应大学，再逐步接近真实备赛

第一学期以学习、练习和建立工程习惯为主，队内强度保持克制，为适应大学课程、生活与个人探索保留弹性。第二学期进入实训后会更接近真实备赛节奏，但压力与责任仍低于正式队员。

机械组更重视长期稳定、可持续和务实的发展。大一入队通常希望拥有至少两年以上的队伍生涯，在充实成长的同时协调好学业、备赛与个人生活，而不是依赖短期突击或间歇性高强度投入。

DEFAULT PATH

循序渐进路径

跟随梯队完成学习期与实习期，赛季末完成结业并晋升正式队员，为第二年承担主力研发做好准备。

OPTIONAL PATH

加速发展路径

少数能力、热情与投入意愿突出的队员，可在本人自愿的前提下获得更多项目机会，同时承担更多责任、工作量与压力。

INTERACTIVE CURRICULUM

默认路径覆盖完整第一学年；加速路径不是单独课程，而是在完成基础培养后按个人发展情况增加真实项目责任。

BASIC TRAINING

寒假集训前完整走完 7 节基础课程

课程按机械工程交付顺序重新排列，从工作原则与建模规范进入材料、结构、轴系和传动，最后用完整流程案例把知识串起来。

CHAPTER 01 · PRINCIPLES
先建立一套能够协作和交付的工作方式

认识机械组从接收任务、定义需求、方案讨论、设计评审到制造、装配、测试和归档的完整工作流，并导入现行 SOP 与基本工作原则。

  • 工作流与责任边界
  • 需求、评审和验收意识
  • SOP 与工程记录
CHAPTER 02 · CAD
理解 Fusion 的建模逻辑，而不只是记住命令

建立草图、约束、参数、组件和装配关系的基本认知，按照组内规范组织模型，为后续复刻作业和模块设计打好工具基础。

  • 参数化建模逻辑
  • 组件与装配关系
  • 文件与建模规范
CHAPTER 03 · MANUFACTURING
让设计从一开始就考虑材料与制造约束

认识常见材料、加工方法、精度、成本和周期，理解不同工艺如何反过来影响结构形式、零件细节与方案选择。

  • 材料特性
  • 加工方法与约束
  • 成本、精度和周期
CHAPTER 04 · FRAME
从机架和基础部件进入结构设计

围绕机器人机架、连接与支撑关系，认识常用基础部件及其使用边界，开始把载荷路径、装配与维护纳入设计判断。

  • 机架与连接
  • 基础部件认知
  • 载荷与装配关系
CHAPTER 05 · SHAFT SYSTEM
通过案例理解轴系的支撑、定位与装配

学习轴、轴承、联接和定位等基本关系，结合案例判断受力、约束、装配顺序与常见失效风险。

  • 轴与轴承
  • 支撑和定位
  • 装配与失效风险
CHAPTER 06 · TRANSMISSION
根据任务选择并构建传动方案

认识常见传动形式、传动比、布置与效率问题，通过案例理解电机、传动元件、执行机构和结构之间的系统关系。

  • 传动形式与选型
  • 传动比和布置
  • 系统匹配
CHAPTER 07 · PROCESS CASE
用案例走通需求、测试与失效闭环

通过完整案例分析需求如何定义、测试如何设计、失效如何定位，并把验证结果重新反馈到下一轮方案和结构设计中。

  • 需求定义
  • 测试方法
  • 失效分析与反馈

职业竞争力不等于会用几款软件，而是能够在复杂约束下持续完成可靠交付。我们把招聘要求拆回工程能力，再说明这些能力如何在 RoboMaster 项目中被训练和证明。

岗位样本观察竞赛经历被关注，但真实贡献才是证据

从多家机器人企业公开的招聘要求中可以看到，RoboMaster、机器人竞赛经历和可验证的工程作品，常被列为优先或加分项；RoboMaster 也已形成面向参赛者的专属招聘通道。但真正产生职业价值的并不是竞赛名称本身，而是你在项目中承担的责任、完成的交付，以及对设计判断、结果与复盘的清晰表达。

CASE 01

舞肌 WUJI

机械结构工程师

项目交付DFM / DFA版本管理
岗位要求提炼
  1. 以项目和版本为单位，按样机、试产与交付节点完成结构模块交付。
  2. 处理零件堆叠、接口定义、公差链和装配路径，解决跨模块集成问题。
  3. 推进 DFM/DFA、模具、工装、试产和装配问题闭环。
  4. 维护三维模型、工程图、BOM、装配资料和工程变更记录。
  5. 识别磨损、变形、振动、异响等风险，并与上下游共同推动结论落地。
竞赛信号

明确将 RM、RC、工程训练大赛经历列为加分项，创始人或队长经历进一步优先。

CASE 02

宇树科技

机械工程师

机器人结构工艺落地生产优化
岗位要求提炼
  1. 开展机器人机械结构设计与新工艺尝试，让方案进入真实产品。
  2. 负责机器人零部件的结构优化、减速器设计及生产问题处理。
  3. 持续提升产品标准化程度、可服务性、交付效率与稳定性。
  4. 具备三维建模、力学分析、材料和机械制造工艺基础。
  5. 重视动手执行、沟通协作、主动学习和对新知识的热情。
竞赛信号

公开岗位将参加机械相关竞赛的经历列为优先条件。

CASE 03

拓竹科技

机械结构工程师

模块开发DFX 评审供应链协同
岗位要求提炼
  1. 从需求拆解到设计落地，承担运动机构、功能机构和外壳等模块的完整开发。
  2. 输出三维、工程图和 BOM，并对成本、质量与交付进度负责。
  3. 开展技术评审与 DFX，识别可制造性、可靠性和结构失效风险。
  4. 制定测试方案，跟进样机验证与生产问题，形成问题闭环。
  5. 与硬件、工艺和供应链紧密协作，推动模块按节奏进入量产。
竞赛信号

明确将 RoboMaster、RMRC 等机器人竞赛经历和真实动手作品列为加分项。

CASE 04

极壳科技

机器人结构工程师

结构仿真装调测试技术文档
岗位要求提炼
  1. 完成机器人结构设计与仿真分析，保障强度、刚度和稳定性。
  2. 与电子、软件和控制团队协同，确保结构与整机系统兼容。
  3. 输出结构零件制造与装配指导资料，参与组装、调试与测试。
  4. 针对测试结果持续优化结构，提高产品性能和生产效率。
  5. 编写设计方案、测试报告和操作手册等完整技术文档。
岗位信号

该岗位没有把竞赛单列为必要条件，更集中考察仿真、装调、测试、文档与跨团队协作的完整性。

CASE 05

智元机器人

人形机器人关节模组工程师

关节模组多物理验证量产工艺
岗位要求提炼
  1. 完成电机、减速器、编码器、传感器、驱动器和轴承等核心器件的选型与集成。
  2. 负责三维建模、零件细化、公差匹配和完整工程资料输出。
  3. 开展静力、动力、疲劳、散热与振动分析，验证关节性能。
  4. 参与样机加工、装配、调试和测试，闭环干涉、卡顿、过热、异响与精度问题。
  5. 衔接整机控制和供应链生产，并跟踪人形关节前沿技术。
岗位信号

岗位把要求推进到专业机器人底层模块，强调跨器件集成、多物理验证和从样机到量产的完整能力。

CASE 06

DJI 大疆

机械结构工程师

系统分析产品交付技术研究
岗位要求提炼
  1. 根据产品功能和需求开展系统分析，将目标转化为合理、创新的结构方案。
  2. 完成产品详细设计，并对设计成本、质量和项目计划负责。
  3. 参与基础性技术研究、专题研究和工程难题攻关。
  4. 具备工程力学、机械结构、材料与常见制造工艺基础。
  5. 重视沟通、闭环思维、动手能力、学习能力以及面对挑战的主动性。
竞赛信号

明确将 RoboMaster、ROBOCON、航模或方程式大赛等赛事经验列为优先条件。

WHAT INDUSTRY EXPECTS

行业在寻找怎样的机械工程师

不同岗位的机器人形态和业务阶段各不相同，但反复出现的是同一组可迁移的工程能力。

需求拆解与系统思维

把产品功能和系统指标转化为结构方案，理解模块边界、整机布局和上下游约束。

结构、机构与接口设计

完成运动机构、传动、接口、公差和装配路径设计，并为成本、质量和进度负责。

分析验证与可靠性

用力学、仿真和失效分析判断强度、刚度、疲劳、热、振动与寿命风险。

制造、DFM/DFA 与量产意识

理解材料、工艺、工程图、BOM、工装和供应链，让设计跨过样机并具备稳定制造条件。

测试、问题闭环与版本交付

制定测试方案，定位异响、磨损、干涉、过热等问题，维护版本资料并完成回归验证。

跨团队协作与结果责任

和电控、算法、工艺、测试与供应链协同，以明确责任、截止时间和退出标准保障项目节奏。
